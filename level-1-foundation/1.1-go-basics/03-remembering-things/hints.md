### Hint 1
Gunakan format `var app string = "Server"` untuk variabel pertama, dan `port := 8080` untuk variabel kedua.

### Hint 2
Untuk memperbarui nilai `port`, jangan gunakan tanda titik dua lagi: cukup tulis `port = 9090`.

### Hint 3
Tulis kode berikut di dalam `main()`:
```go
var app string = "Server"
port := 8080
port = 9090

fmt.Println(app)
fmt.Println(port)
```
