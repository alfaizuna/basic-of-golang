### Hint 1
Untuk mengubah elemen pertama pada array `arr`, akses menggunakan indeks 0: `arr[0] = 99`.

### Hint 2
Bentuk fungsi `modifyCopy`:
```go
func modifyCopy(arr [3]int) [3]int {
	arr[0] = 99
	return arr
}
```

### Hint 3
Cukup tambahkan baris `arr[0] = 99` sebelum `return arr` di dalam fungsi `modifyCopy`.
